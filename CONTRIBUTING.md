# Contributing to PyDocAI

We love contributions! Here's how you can help.

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/your-username/PyDocAI.git`
3. Create a feature branch: `git checkout -b feature/my-feature`
4. Make your changes
5. Push and open a Pull Request

## Development Setup

See [README.md](README.md#quick-start) for local setup instructions.

## Guidelines

- **Code style** — Follow existing patterns in the codebase
- **Commits** — Use clear, descriptive commit messages
- **One PR = one feature/bug fix** — Keep changes focused
- **Tests** — Add tests if applicable

## Reporting Bugs

Open an [issue](https://github.com/dennisjoseph2025/PyDocAI/issues) with:
- A clear title and description
- Steps to reproduce
- Expected vs actual behavior
- Screenshots if relevant

## Feature Requests

Open an [issue](https://github.com/dennisjoseph2025/PyDocAI/issues) with:
- What you'd like to see added
- Why it would be useful
- Any implementation ideas

## Pull Request Process

1. Ensure your code builds and lints cleanly
2. Update documentation if needed
3. Your PR will be reviewed as soon as possible

## Code of Conduct

Be respectful and constructive. We're all here to build something great.
